# DailyRoastWeb

Aplicación web para administrar productos de una cafetería.

## Tecnologías

- Frontend: React, Vite, PrimeReact y Axios.
- Backend: Node.js, Express y Mongoose.
- Base de datos: MongoDB.
- Pruebas: Jest y Supertest.

## Estructura

- `frontend/`: interfaz web.
- `backend/`: API REST y conexión a MongoDB.

## Requisitos

- Node.js y npm.
- MongoDB instalado y en ejecución.
